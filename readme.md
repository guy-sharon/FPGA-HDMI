# FPGA-HDMI

This is an implementation of the High-Definition Multimedia Interface (HDMI) protocol, written for Cmod S7-25 (xc7s25csga225-1).
<br/>
This project includes both video (VGA, 640x480) and audio, and is based upon the [HDMI Specification Version 1.3](https://engineering.purdue.edu/ece477/Archive/2012/Spring/S12-Grp10/Datasheets/CEC_HDMI_Specification.pdf).
